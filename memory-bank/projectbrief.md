# Project Brief

## Core Purpose
A cross-platform trip meter, transit navigation, and kitchen/stock inventory system (BiyaheMeter) that tracks real-time location metrics, routes, fares, and inventory data across mobile and desktop devices.

## Scope
- [x] Phase 1: Core navigation, map tracking, CRUD operations, and macOS-inspired desktop/mobile UI.
- [ ] Phase 2: Real-time database synchronization, offline persistence, and cloud synchronization.
- [ ] Phase 3: Automated alerts, low-stock / route cost analytics, and report generation.
